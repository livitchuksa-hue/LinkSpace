# Linkspace

Настольное приложение для Windows: интерактивный граф, в котором в одном
пространстве живут заметки, локальные файлы и папки, а также интернет-ссылки.
Узлы можно перемещать, связывать между собой, визуально группировать в
тематические области и фильтровать. Данные хранятся локально в SQLite и
восстанавливаются после перезапуска.

## Возможности

### Объекты и граф

- **Четыре типа объектов**: заметки, файлы, папки, интернет-ссылки.
- **Интерактивный граф**: перетаскивание узлов, изменение их размера,
  панорамирование с инерцией (граф «докатывается» после резкого движения),
  масштабирование колесом к курсору (0.2–3.2×), фоновая сетка.
- **Связи** между любым двумя объектами: создание через контекстное меню
  или инструмент «Связать», подписи и цвета, z-порядок.
- **Визуальные области** трёх форм: произвольный полигон (со сглаженными
  контурами), прямоугольник, эллипс. Области можно рисовать, двигать,
  редактировать вершины и размер, узлы внутри области перемещаются вместе
  с ней. Названия областей отображаются поверх объектов.
- **Слои (z-order)** для объектов, связей и областей через контекстное меню.
- **Drag-and-drop** файлов и папок прямо на канвас.
- **Горячие клавиши**: `Del` — удалить выбранное (с подтверждением),
  `Enter` — завершить область, `Esc` — отмена/закрытие модалки/снятие
  выделения.

### Превью и содержимое

- **Изображения** (png, jpg, webp, gif, svg и др. до 25 МБ) показываются
  как фон карточки файла.
- **Текстовые файлы** — сниппет содержимого прямо на карточке.
- **Markdown-заметки**: заметку можно привязать к `.md`-файлу — файл
  становится источником истины (читается при редактировании, пишется
  при сохранении). На карточке markdown очищается от разметки.
- **Ссылки**: автоматическая «распаковка» страницы — заголовок, описание,
  `og:image` как фон карточки и favicon в чипе типа.
- **Правая панель свойств**: метаданные (диск, даты создания/изменения/
  открытия), теги, превью ссылки и отформатированный просмотр markdown.
  Большой текст открывается в отдельной почти полноэкранной модалке
  с прокруткой («Просмотреть текст»).

### Теги

- Теги с именем и цветом на любых объектах.
- Автодополнение из реестра существующих тегов + создание новых.
- Отображение на карточках и в панели свойств; фильтрация по тегам.

### Фильтрация

Плавающая панель фильтров вверху канваса (появляется при наведении на
верхний край, скрывается при рисовании области):

- по **типу** объекта, **диску**, **тегам** (выпадающий список с
  чекбоксами) и **датам** (создан / изменён / открыт, диапазон);
- неподходящие объекты и связи становятся полупрозрачными;
- счётчик совпадений и кнопка сброса;
- фильтр сохраняется между запусками.

### Интерфейс

- **Плавающие панели** слева (инструменты) и справа (свойства) с
  возможностью закрепления.
- **Настройки** в модалке по центру: видимость полей карточек, форма
  областей по умолчанию, редактирование вершин областей.
- Адаптивные карточки: содержимое масштабируется вместе с размером
  карточки, текст на фото-фонах снабжён тенью для читаемости.
- Пропавшие файлы помечаются на карточках.
- Тёмная минималистичная тема с цветами типов объектов и областей.

## Технологии

| Слой | Стек |
|------|------|
| Frontend | HTML5, CSS3, JavaScript, Vue 3, Vite, markdown-it |
| Desktop | Electron (Main Process, Preload, IPC) |
| Backend | Java 21, Spring Boot 3.x, Maven, REST API |
| Database | SQLite + SQLite JDBC + Spring JDBC |

## Требования к окружению

- **Node.js** 18+ и **npm**
- **Java JDK 21+** (проект компилируется под Java 21; более новые JDK могут работать, но для стабильной проверки лучше использовать 21)
- Maven Wrapper уже включён в `backend/` — отдельная установка Maven не обязательна

## Структура проекта

```text
Linkspace/
├── frontend/   # Vue 3 + Vite + Electron
├── backend/    # Spring Boot + SQLite
├── docs/       # Документация API
└── README.md
```

## Установка зависимостей

```powershell
cd frontend
npm install
```

Зависимости backend Maven скачиваются автоматически при первой сборке или запуске через `backend/mvnw.cmd`.

## Запуск приложения

### Рекомендуемый способ: Electron + Vite + backend автоматически

```powershell
cd frontend
npm run electron:dev
```

Команда:

1. запускает Vite dev-сервер на `http://127.0.0.1:5173`;
2. запускает Electron;
3. автоматически поднимает Spring Boot backend, если он ещё не запущен;
4. при закрытии окна останавливает backend, если его запустил сам Electron.

В режиме разработки backend запускается через Maven Wrapper, поэтому изменения в Java-коде подхватываются после перезапуска `electron:dev`.

> **Важно:** если на порту 8080 уже работает старый процесс backend
> (например, от прошлого запуска), Electron подключится к нему, а не
> запустит новый — тогда новые поля (теги, превью) могут не сохраняться.
> Закройте все окна Linkspace и старые java-процессы перед перезапуском.

### Production-режим Electron

Сначала соберите frontend и backend:

```powershell
cd backend
.\mvnw.cmd -DskipTests package

cd ..\frontend
npm run build
npm run electron
```

В этом режиме Electron использует собранный `backend/target/linkspace-backend-0.1.0-SNAPSHOT.jar`, если он существует.

### Только frontend в браузере

```powershell
cd frontend
npm run dev
```

Затем в отдельном терминале запустите backend:

```powershell
cd backend
.\mvnw.cmd spring-boot:run
```

Frontend по умолчанию обращается к `http://127.0.0.1:8080/api`.
В браузерном режиме файловые функции (диалоги, превью, markdown-файлы)
недоступны — для полной функциональности используйте Electron.

## Полезные команды

| Команда | Описание |
|---------|----------|
| `npm run dev` | Vite dev-сервер |
| `npm run build` | Сборка frontend в `dist/` |
| `npm run electron` | Electron против собранного `dist/` |
| `npm run electron:dev` | Vite + Electron + автоматический backend |
| `npm run electron:build` | Сборка установщика через electron-builder |
| `.\mvnw.cmd spring-boot:run` | Backend вручную |
| `.\mvnw.cmd -DskipTests package` | Сборка backend JAR |
| `.\mvnw.cmd test` | Тесты backend |

## Данные

SQLite-файл создаётся здесь:

```text
backend/data/linkspace.db
```

В базе хранятся объекты (включая теги, кастомные цвета/размеры и превью
ссылок), связи, области, координаты узлов, z-порядок, настройки
отображения и фильтры, а также дата последнего открытия объекта.
Схема создаётся автоматически (`schema.sql`), новые колонки
добавляются миграциями при старте backend (`SchemaMigration`).

## Статус проекта

Текущая версия включает полный цикл работы с графом: CRUD объектов,
связей и областей, теги, фильтрация, превью (изображения, текст,
markdown, ссылки), markdown-заметки с файлами, локальное хранение в
SQLite и автоматический запуск backend из Electron.
